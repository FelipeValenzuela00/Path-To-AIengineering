# Programa: Python + AI Engineering

Programa de 12 semanas (~10 h/semana) para pasar de "uso APIs de IA" a "construyo sistemas de IA con Python, evaluados y desplegados", y terminar con un portafolio público y un CV actualizado.

## Archivos
- [`PLAN.md`](PLAN.md): plan semana a semana con checklist.
- [`SETUP.md`](SETUP.md): instalación de herramientas.
- `notas/`: una nota breve por semana.
- `fase1-python/` … `fase5-agentes-prod/`: proyectos.
- `cv/`: CV actualizado y checklist de enlaces.
