# Path-To-AIengineering
En este repositorio expondré (de manera vergonzosa) mi camino para dirigirme hacia un desarrollador enfocado en inteligencia artificial. Ya realicé algunos proyectos con apis de AI, en otros idiomas, pero la meta es volverme capaz de crear sistemas confiables con inteligencia artificial y python

## El programa

Programa de 12 semanas (~20 h/semana) para pasar de "uso APIs de IA" a "construyo sistemas de IA con Python, evaluados y desplegados", y conseguir trabajo en el sector con un portafolio público y un CV actualizado.

## Archivos
- [`PLAN.md`](PLAN.md): plan semana a semana con checklist.
- [`SETUP.md`](SETUP.md): instalación de herramientas.
- `notas/`: una nota breve por semana.
- `fase1-python/` … `fase5-agentes-prod/`: proyectos.
