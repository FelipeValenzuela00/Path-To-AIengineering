# Fase 1: Python profesional (semanas 1-2)

**Objetivo:** escribir Python idiomático, tipado y testeado, con un entorno reproducible.

## Temas
`uv`, tipado, `dataclasses`, `pydantic`, comprensiones, generadores, context managers, decoradores, `async/await`, `pytest`, `ruff`, GitHub Actions.

## Proyecto 1
CLI útil (organizador de archivos, cliente de una API pública, etc.) con tests y CI.

## Terminado cuando
- [ ] `uv run pytest` en verde
- [ ] `ruff check` sin errores
- [ ] CI pasando en GitHub
- [ ] README con problema, uso y ejemplos
